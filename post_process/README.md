# Files related to post-processing of the output from the model.

* comp_sim_obs_UKESM1_1.py -- script to compute simulated values.
* land_frac.nc -- land fraction file. 1 for all land, 0 for all sea.
* simobs_wrapper.sh -- wrapper script to run the comp_sim_obs_UKESM1_1.py script.
* pp_config.json -- std configuration  for the post-processing scripts
* pp_config_ts.json -- configuration for post processing AMIP data to give timeseries data.
